# Material complementario del TFM

Este repositorio contiene el material complementario asociado al Trabajo de Fin de Máster:

**Estudio comparativo de estrategias de control individual del ángulo de palas en aerogeneradores offshore flotantes**

## Contenido

- `Modelo/IEA-15-240-RWT_v4.1/`: archivos de configuración del modelo OpenFAST.
- `Casos_simulacion/`: configuraciones empleadas para los casos base y controladores.
- `Matlab/Scripts/`: scripts de postprocesado, cálculo de métricas y generación de figuras.
- `Matlab/Matlab_Toolbox/`: funciones auxiliares para lectura y tratamiento de resultados.
- `Resultados/Figuras_Memoria/`: figuras utilizadas en la memoria y anexos.

## Reproducción del postprocesado

Para reproducir los resultados es necesario actualizar en los scripts de MATLAB la variable correspondiente al directorio raíz del proyecto.

Las simulaciones de OpenFAST deben ejecutarse previamente. Por motivos de tamaño, determinados archivos de salida completos no se incluyen en el repositorio.
